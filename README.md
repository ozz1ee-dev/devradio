# DevRadio

DevRadio (devradio.co.uk) is a 24/7 internet radio station. It plays lo-fi music and short English bulletins on AI and software development, including two-host dialogues. The voices are AI-generated and that is disclosed on air. The stream runs on AzuraCast.

The station is community-curated. Tracks are submitted as pull requests to this repository.

Full contribution docs are in an upcoming pull request.
